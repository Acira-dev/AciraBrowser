Acira does not modify that source file; the separately authored adapter uses a compatible subset described below.

Actual Ghostery parser/network rules are reused. The adapter requests maintained generic rules for reviewed common consent managers plus compatible rules scoped to the current hostname. Only generated CSS hiding selectors are used in the inert frame runtime; extended selectors, scriptlets and custom style declarations are excluded. This keeps the per-frame rules bounded and avoids arbitrary script or style/resource loading. Ordinary MutationObserver scans support late/SPA banners and individual Show reverses display changes. Existing site/profile/temporary disable choices restore hidden DOM. No Accept/Reject button is clicked and no consent preference/cookie is written. Hiding is not consent rejection or universal banner coverage; unsupported scroll-lock/custom-style layouts can require temporarily disabling the optional filter. The list is bundled offline in this milestone; automatic refresh of this optional list is not yet claimed.
