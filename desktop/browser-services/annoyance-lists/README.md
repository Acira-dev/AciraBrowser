Acira does not modify that source file; the separately authored adapter uses a compatible subset described below.

Actual Ghostery parser/network rules are reused. The adapter requests maintained generic rules for reviewed common consent managers plus compatible rules scoped to the current hostname. Only generated CSS is used in the inert frame runtime: hiding selectors and the lists' `:style()` declarations (they release a banner's scroll lock); extended selectors and scriptlets are excluded, so the lists' click-to-accept scriptlets never run. Acira adds one generic pair for Sourcepoint, whose container id carries a per-site number: the container is hidden and its `html.sp-message-open` lock released (uBlock's own per-site rule). This keeps the per-frame rules bounded and avoids arbitrary script or style/resource loading. Ordinary MutationObserver scans support late/SPA banners and individual Show reverses display changes. Existing site/profile/temporary disable choices restore hidden DOM. No Accept/Reject button is clicked and no consent preference/cookie is written. Hiding is not consent rejection or universal banner coverage. For a few seconds after a banner is hidden, an empty see-through veil it left over the window is hidden and a leftover scroll lock released; a site's own dialogs (anything with content in it, or anything that opens after the person clicks or types) are never touched, and a page that stays blocked gets its banner back. The list is bundled offline in this milestone; automatic refresh of this optional list is not yet claimed.
