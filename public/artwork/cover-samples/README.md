# Cover samples (setup, "Choose a new tab cover"; Settings › New tab background)

Six JPEGs that stand for the new tab's collections in setup's cover step (the cards and the preview) and in Settings › Appearance › New tab background, so both show a finished picture without any network request:

- `paintings.jpg` — a crop of the default painting shipped in `../catalog-v2` (museum open access, CC0).
- `landscapes.jpg`, `nature.jpg`, `architecture.jpg`, `space.jpg` — one real photograph each from the matching Wikimedia Commons collection, 640 × 360.
- `own.jpg` — a blurred painting detail behind the "add your own" mark.

Where each picture comes from, who made it and under which licence: [CREDITS.md](CREDITS.md). The remote collections only use these previews during setup and in Settings (setup labels them "Example"); the real pictures are fetched later, one at a time, when a new tab is opened.
